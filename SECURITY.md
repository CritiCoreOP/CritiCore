# Security

Please do not report security issues in public GitHub issues.

Write to **support@criticore.cc** with the subject "Security" and describe:

- what is affected (page, endpoint or edge function),
- how to reproduce it,
- what an attacker could do with it.

We answer within a few days and fix confirmed issues as quickly as we can. Please give us time to fix an issue before you publish details.

No secrets, keys or production data are part of this repository. If you find one anyway, report it the same way.
